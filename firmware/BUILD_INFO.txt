ESPet Firmware Build
====================
Status: Not yet built – run `pio run` locally or push to trigger GitHub Actions CI.

Files (generated by CI)
-----------------------
firmware_wokwi.bin  → Wokwi web simulator (SSD1306 display driver)
firmware_sh1106.bin → Real hardware: AZ-Delivery 1.3" OLED (SH1106)

Flash command (real hardware)
------------------------------
esptool.py --chip esp32 --port /dev/ttyUSB0 --baud 460800 \
  write_flash -z 0x1000 firmware_sh1106.bin

Local build
-----------
# Wokwi (DISPLAY_SSD1306 aktiv in platformio.ini):
pio run
cp .pio/build/esp32dev/firmware.bin firmware/firmware_wokwi.bin

# Real hardware (DISPLAY_SH1106 aktiv):
# platformio.ini: kommentiere DISPLAY_SSD1306 aus, aktiviere DISPLAY_SH1106
pio run
cp .pio/build/esp32dev/firmware.bin firmware/firmware_sh1106.bin
